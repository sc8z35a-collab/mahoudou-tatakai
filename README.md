# ASHEN CROWN — 灰冠の剣士

## 概要・目的
王城エルドリアの玉座の間でNPC「王城の守護者」と1対1の剣術決闘を行う、スマートフォン横画面向け3Dブラウザーゲーム。HTML・CSS・JavaScript・Three.jsで動作する静的サイトで、バックエンドやビルド処理は不要です。

## 背景・フィールド拡張（今回の更新）
- 約2,500部品の建築装飾・小物を追加。100以上の小物クラスターとして、書き物机、本、巻物、杯、蝋燭、ベンチ、樽、鉄帯の宝箱、武器ラック、壺、石像、硬貨、瓦礫を配置。
- 壁の腰板・浮き彫りパネル、金属の見切り、持ち送り、柱頭彫刻、ロゼット、天井の格子、巨大な木製入口扉を追加。
- 2048pxの大理石床テクスチャと床の紋章。石目、割れ、タイル縁、幾何学文様、古びた金の線、模様入り絨毯を手続き生成。
- 主光源の4096pxシャドウ、窓格子と色ガラス模様を投影する3灯のスポットライト、暖色・寒色の補助光、SSAO接触陰影、既存のブルーム・霧を組み合わせたライティング。
- 静止した背景部品は材質単位でジオメトリを統合。見た目を維持しながら描画呼び出し数を抑制。
- 旧移動制限（X ±8.2、Z -16.5〜11）を廃止。城内の実際の壁まで移動でき、側廊、入口付近、玉座の6段の階段と壇上に到達可能。
- 120以上の衝突形状を登録。壁・腰板、柱の四角い台座／円柱、燭台の足／支柱／鉢、回転した家具、宝箱、樽、武器ラック、石像、壺、玉座を、高さと向きを含めて処理。
- プレイヤーの本体半径は0.32。移動・回避・ノックバックを最大0.08単位ごとに分割して衝突検査し、薄い物体のすり抜けを抑制。0.27の階段を上り下りし、足裏も壇上の高さに追従。
- NPCは0.45間隔のナビゲーショングリッドとA*で柱・家具を迂回。経路の各区間も同じ衝突形状で再検査。
- 剣の命中は遮蔽物の視線判定を追加し、柱越しの攻撃を禁止。カメラも障害物までのレイで距離を短縮し、壁際では横方向の候補に回り込む。
- 停止中の不必要な3D再描画を省略。画質変更・リサイズ・検証姿勢変更時は再描画。

### 拡張版の検証
- **113/113項目のテスト合格**。旧87項目を新しい実壁の仕様に合わせて更新し、拡張エリア、全6段の上り下り、玉座・柱・燭台・机の衝突、高速移動、回転家具、NPC迂回、経路の実走行、壇上の接地、カメラ衝突、遮蔽物越しの攻撃を追加検証。
- 実描画で中央大広間（デスクトップ）、新たに移動可能な側廊（モバイル390×844）、玉座の壇上（デスクトップ）を確認。UIの可読性、接地、カメラ位置、背景の装飾・陰影を確認。
- 小さな硬貨・低い瓦礫・布・卓上小物は視覚用装飾で、個別に動かす物理シミュレーションは未実装。衝突は形状に合わせた円柱・回転ボックスと段差面の組み合わせであり、全三角形メッシュ同士の厳密な衝突ではありません。
- ステージは既存の大広間全体の拡張であり、扉の外や別の部屋へは移動できません。NPCの非常に狭い隙間での経路選択や全接触角度は実機で継続確認が必要です。

## 実装済み機能
### ステージ・グラフィック
- 実際のWebGL 3D描画、三人称追従カメラ、敵への自動ロックオン。
- 石造りの大広間、列柱、アーチ、装飾窓、玉座・階段・旗・シャンデリア・燭台・床の決闘用インレイ。
- 1024px石材／2048px大理石・紋章テクスチャ、主光源4096pxシャドウマップ、ACESトーンマッピング、ブルーム、霧、塵、炎の揺らぎ。
- ULTRA（端末DPRに応じて最大3倍解像度）／HIGH（最大2倍）／STANDARD（等倍）。初期設定はULTRA。

### 今回強化した剣士・武器・モーション
- 人体比率を調整した剣士2体。曲面をロフトした胸甲・兜・脚甲、重なる装甲板、鋲、装飾線、鎖帷子、革ベルト、鞘、分節化した足甲、揺れるマント。
- プレイヤーの逆向きの剣を修正。モデルの前方は+Z、解剖学的な右手は-X。剣は手を基準に取り付け、カメラや体の向きが変わっても構えた刃先が後方へ反転しないよう統一。
- 4本の指と親指の籠手で柄を包む造形。鍔、巻き柄、柄頭、菱形断面の刃、樋、刻印を個別に作成。
- PMREM環境反射、金属の傷・粗さ、織り目、鎖帷子のテクスチャ／バンプ表現。部位ごとに金属・革・布を分離。
- 胴体・骨盤・肩・肘・手首・膝・足首を持つリグ。予備動作→加速した斬撃→振り抜き→構えへの復帰を補間。
- 斜め斬り／返し斬り、腰と肩の回転、踏み込み、歩行方向に応じた足運び、防御への補間、屈んで回避、被弾・倒れる動作、移動と捻りに追従するマント。
- 足裏の接地補正。実際の刃先座標を短時間記録した細いライン状の斬撃軌跡。広い半透明の斬撃面は使用しません。
- 剣士に大きな三角形として重なって見える城内の平面光芒メッシュを削除。雰囲気はライト・霧・塵で維持。

### 戦闘・操作
- タッチスティック移動、攻撃、防御長押し、方向回避。Pointer Eventsとpointer captureを使用。
- NPCの接近、横移動、予備動作付き攻撃、防御。難易度3段階。
- HP、スタミナ消費と回復、射程・前方判定、1斬撃につき1回の命中、回避中の無敵。
- 火花、カメラシェイク、被弾表示。Web Audioによる剣の風切り音・金属音・被弾音・低音アンビエンス。初期サウンドOFF。
- 開始、勝敗判定、結果、再戦、タイトル復帰、一時停止、設定・操作ガイド。
- 非表示／フォーカス喪失時の停止。対応ブラウザーで全画面と横向きロックを要求。縦画面には回転案内。

## 不具合点検で修正した項目
- 再戦・タイトル復帰時に古い結果表示タイマーが残る問題：タイマー取消とラウンドID確認。
- 最終被弾時のHP表示更新漏れ・負数HP：即時更新と0下限。
- スタミナ不足でも防御できて負数になる問題：防御に20必要、値を範囲内に制限。
- 後ろへの攻撃や背後からの攻撃を盾で防ぐ問題：前方判定。
- 防御長押し中の攻撃後に防御が復帰しない問題：押下状態と実際のガード状態を分離。
- 複数の指／キーボードとタッチの併用時に解除が競合する問題：ポインター集合管理。
- 停止・画面サイズ変更・背景化後に移動入力が残る問題：入力とcaptureの解除。
- 設定を閉じると別の停止ダイアログが開いていても戦闘が再開する問題：停止状態を集約。
- フォーカス喪失で設定の上に停止ダイアログが重なる問題：既存のdialogを確認。
- 大きいフレーム時間で回避距離が延びる問題：残り回避時間で移動量を制限。
- プレイヤーと敵が完全に同じ位置になった際の分離不良：ゼロ距離の処理を追加。
- 燭台へのめり込み、ノックバックで境界外に出る問題：障害物と境界の補正。
- 再戦時の斬撃軌跡・火花・被弾表示・歩行・コンボの残留：一括リセット。
- 戦闘更新を最大1/60秒の小刻みに分割し、描画フレームに依存する差を抑制。
- 重複する城内アーチを削除。カメラが列柱に入り込みにくい横方向範囲へ制限。
- 外部モジュール読み込み／WebGL初期化に失敗した際の無限ローディング：エラー案内と再読み込みボタン。
- WebGLコンテキスト消失時の停止・復帰処理、反射用環境テクスチャの再生成。

## 起動URIとパラメーター
- `/` または `/index.html`：通常のタイトル画面。テストは自動実行されません。
- `/index.html?play=1`：タイトルをスキップして決闘を開始。
- `/index.html?selftest=1`：開発用113項目のスモーク／回帰テスト。結果をコンソールに表示後、確認用戦闘状態で停止。通常プレイには使用しないでください。
- `/index.html?selftest=1&pose=windup`：振りかぶりの姿勢確認。
- `pose=cut` / `pose=recovery` / `pose=guard` / `pose=dodge`：斬撃・復帰・防御・回避の確認。`selftest=1`と併用。
- `/index.html?selftest=1&area=aisle`：新しい側廊での描画確認。`area=throne`：玉座の壇上。`pose`との併用も可能。
- 設定、操作ガイド、一時停止、結果は同一ページ上のネイティブdialogです。

## 操作
| 操作 | スマートフォン | PC |
|---|---|---|
| 移動 | 左スティック | WASD / 矢印 |
| 攻撃 | 右側の大きな剣ボタン | J / 画面左クリック |
| 防御 | 防御ボタン長押し | K長押し |
| 回避 | 回避ボタン | Space |
| 一時停止 | 左下PAUSE | Escape |

敵の剣が赤く光るのは予備動作です。攻撃17、防御成功20、回避25のスタミナを使用。自分のHPは100、敵は150。サウンドは右上の音符からONにできます。

## 検証結果
- **113/113項目の自動テスト合格**。開始、射程、命中回数、防御、無敵、消耗と回復、NPC、停止／再開、設定、勝敗、再戦を検証。
- 両剣士それぞれの4方向での剣先方向、左右の手の取り付け、握り位置、2斬撃×101姿勢サンプルの数値安定性と構えへの連続性を検証。
- 両剣士のメッシュ頂点と、2斬撃中の足裏位置を検証。
- 入力・境界条件・古いタイマーの取消・複数ダイアログ・描画バッファ寸法・軌跡消滅を検証。
- 600ステップの統合戦闘シミュレーションでHP・スタミナ・座標の健全性と実際の命中を確認。
- デスクトップ1280×800、モバイル390×844の実描画で剣士とUIを確認。最終斬撃姿勢とモバイル防御表示で、広い三角形の重なりがなくなったことを確認。
- テスト用HTML属性を除去し、通常起動のコンソールでテストが自動実行されないことと、JavaScriptエラーがないことを確認。
- テスト用のソフトウェアWebGL環境にはGPU stall等の環境警告があります。

### 未検証事項・限界
全環境での無欠陥を保証するものではありません。次は未検証です：
- 実際の高性能スマートフォンでの横画面・物理的な同時タッチ・温度上昇・FPS・音声出力。
- 実機Safariの全画面／横向きロック、実GPUのコンテキスト消失からの復帰、外部CDNが障害中の実ネットワーク挙動。
- すべての姿勢やカメラ角度での装甲・布・武器同士の微細な接触。モーションキャプチャ、物理布、地形追従フルボディIK、剣メッシュ同士の厳密な接触判定ではありません。

## 構成とデータモデル
```text
index.html           タイトル・HUD・タッチUI・各ダイアログ
css/style.css        横／縦画面対応UI
js/boot.js           初期化と読み込み失敗時の案内
js/game.js           城内・戦闘ルール・入力・音声・状態管理
js/knight.js         剣士モデル・PBR材質・リグ・モーション・軌跡
js/castle-detail.js  背景小物・装飾・テクスチャ・ライティング・形状登録
js/field.js          高さ付き衝突形状・移動解決・階段・A*・カメラ遮蔽
 tests/smoke.js      基本戦闘と武器・モーションのテスト
 tests/regression.js 境界条件と統合回帰テスト
 tests/field.js      拡張フィールド・段差・経路・カメラのテスト
README.md            このドキュメント
```
- `player` / `enemy`：モデル、胴体・骨盤・腕・脚の関節、握り基準・刃先、HP、スタミナ、攻撃、回避、被弾、AIタイマー。
- `motion`：速度、移動方向、防御・被弾・死亡の補間値。`trailHistory`：短寿命の刃先座標。
- `mode`：`title` / `battle` / `result`。`paused`はモーダル・ページ非表示・コンテキスト消失を反映。
- `field.solids`：名前・位置・形状・高さ・角度を持つ静的衝突データ。`field.surfaces`：歩ける段差面。`field.grid`：生成されたNPC経路用グリッド。保存サービスは不使用。
- `castle.stats`：背景の部品数・小物クラスター数・衝突形状数。`castle.batch`：材質別の統合ジオメトリ。
- `roundId`とタイマーで結果表示を管理。`effects`は寿命終了／再戦時にdispose。
- 永続ストレージなし。設定・戦績はリロードで初期化。Table API、DB、認証、アップロードストレージは不使用。
- モデルとテクスチャはブラウザーで生成。外部の3Dアセット・画像生成は不使用。
